# System Information

## Objective

The objective of this lab is to inspect a Windows computer using PowerShell and document its operating system and hardware specifications.

## Operating System

- Edition: Windows 11 Home
- Architecture: 64-bit
- Build: 26300

## Hardware

- CPU: Intel Core 5 120U
- RAM: Approximately 16 GiB

## Tools Used

- `PowerShell`
- `Get-ComputerInfo`
- `Get-CimInstance`

## What I Learned

- How to retrieve system information using PowerShell.
- How to filter command output using `Select-Object`.
- How to convert memory values from bytes to GiB.
- Why it's important to verify system information using multiple sources.
